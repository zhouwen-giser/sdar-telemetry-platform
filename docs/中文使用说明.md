# 中文使用说明

1. 准备 Node.js 22、外部 ClickHouse ≥24.8 和控制 PostgreSQL。
2. 复制 `.env.example` 为 `.env`，密码写入 `deploy/secrets/`，不要写入环境文件。
3. 执行 `npm run verify`。
4. 执行 ClickHouse preflight/migrate/verify/smoke。
5. 通过 `docker compose -f deploy/compose.external-clickhouse.yaml --profile dev-control-postgres up --build` 启动开发环境。默认 Compose 不创建 ClickHouse。
6. SDAR Relay 只读取事务 Outbox 并在 WAL ACK 后更新 delivery metadata；不得写业务权威表。
